# Superstore-Sales-Analysis
Exploratory data analysis of global superstore sales data

## 📊 Project Overview
This project analyzes the Sample Superstore dataset to uncover insights about sales, profit, customer segments, shipping efficiency, and discount impact.  
The final deliverable is a fully interactive Excel dashboard supported by clean data, pivot table analysis, and documented findings.

This project demonstrates:
- Data cleaning & preparation (Power Query)
- Exploratory analysis (Excel Pivot Tables)
- Data visualization (PivotCharts & KPIs)
- Dashboard design for business insights
- Clear communication of findings

## 🧼 Data Cleaning (Power Query)

Steps:
1. Loaded raw CSV into Power Query  
2. Removed duplicates  
3. Standardized data types (dates, text, numbers)  
4. Split Order Date into **Year** and **Month Name**  
5. Fixed formatting inconsistencies  
6. Loaded cleaned data back to Excel as a table  

Output file: `data/cleaned_data.xlsx`

---

## 🔍 Exploratory Analysis (Pivot Tables)

Key Pivot Tables created:
- Profit by Category  
- Profit by Sub-Category  
- Sales by Region  
- Sales by Segment  
- Discount Impact on Profit  
- Shipping Mode Performance  
- Sales Trend by Month & Year  
- Total Orders KPI (Count of Order ID)

Stored in: `analysis/pivot_tables.xlsx`

## 📊 Final Dashboard

The dashboard includes:
- 4 KPI Cards (Sales, Profit, Orders, Quantity)
- Sales by Category chart
- Profit by Sub-Category chart
- Discount vs Profit chart
- Shipping Mode performance chart
- Monthly/Yearly trend chart
- Interactive slicers (Region, Category, Segment)
- Timeline filter for Order Date

File: `dashboard/dashboard.xlsx`

Screenshots available in the `screenshots/` folder.

## 📈 Key Insights

- Technology is the highest-profit category  
- Furniture struggles with low profit margins  
- High discounts significantly reduce profit  
- Standard Class shipping is the most commonly used  
- West region performs strongly; Central underperforms  
- Sales show clear monthly and yearly trends
