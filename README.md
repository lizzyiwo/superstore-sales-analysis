# Superstore Sales & Profit Performance Dashboard

## 📊 Project Overview
This project analyzes the Sample Superstore dataset to uncover insights about sales, profit, customer segments, shipping efficiency, and discount impact.  
The final deliverable is a fully interactive Excel dashboard supported by clean data, pivot table analysis, and documented findings.

This project demonstrates:
- Data cleaning & preparation (Power Query)
- Exploratory analysis (Excel Pivot Tables)
- Data visualization (PivotCharts & KPIs)
- Dashboard design for business insights
- Clear communication of findings
